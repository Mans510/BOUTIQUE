# MANS BOUTIQUE — Haute Couture & Bespoke Ethnic Wear Website

A world-class, modern, premium, and fully responsive website designed for **MANS BOUTIQUE**, a luxury Indian ladies fashion boutique specializing in bespoke bridal blouses, royal micro-velvets, artisanal zardozi embroidery, and draped ethnic silhouettes.

Designed with an editorial luxury aesthetic inspired by premier fashion ateliers and high-end Indian couture brands.

## 🎨 Visual Identity & Design System

- **Primary Brand Color**: Royal Burgundy & Maroon (`#460912`, `#270409`) — derived directly from the official MANS BOUTIQUE embossed logo.
- **Accent Color**: Regal Burnished Gold (`#D4AF37`, `#F4E4A6`, `#A87D1E`) with shimmer gradients.
- **Foundation Palette**: Soft Ivory & Champagne Cream (`#FAF7F2`, `#F4EFE6`) providing generous whitespace and editorial serenity.
- **Jewel Tones**: Emerald Green (`#0D3325`) and Sapphire Navy (`#0E274A`) extracted from the boutique's signature garments.
- **Typography**:
  - Headlines: `Cinzel` & `Cormorant Garamond` (Regal Roman serif & Italian editorial style).
  - Body & UI: `Plus Jakarta Sans` & `Montserrat` (Clean, contemporary, highly readable luxury typography).

## 🚀 How to Run the Website

### Option 1: Direct Browser Launch (Zero dependencies required)
Simply navigate to `d:\CLOUD COMPUTING` and double-click:
```
index.html
```
The website is completely self-contained and will run in Chrome, Edge, Safari, or Firefox with full styling, interactions, and imagery.

### Option 2: Local HTTP Server (Node.js)
You can run the built-in HTTP server:
```bash
npm start
```
or
```bash
node server.js
```
Then open your web browser to:
```
http://localhost:3000
```
